Why this is different

Survivorship-bias corrected

Tests run against real point-in-time S&P 500 membership — including the companies that were removed. Most backtests quietly delete the losers, which inflates returns by roughly 2.6–4.3%/yr.

An honesty badge on every result

Every winner is re-checked on held-out data. If it decays out-of-sample, we say so instead of hiding it.

Six strategy classes, not one-size-fits-all

Trend, breakout, mean reversion, volatility stops, dual momentum and factor scoring — compared per stock, per timeframe.

Transparent about its stage

This is an early research prototype built by an independent developer. No fake testimonials, no invented user counts, no logos.
